# Веб-старт — моя первая страница

Проба по HTML и CSS для новичков. Ученик создаёт страницу-визитку и сразу видит результат рядом с кодом.

## Как открыть

Готовая версия на сервере: https://31-76-227-64.sslip.io/weblab/

Для запуска этой копии на компьютере открой терминал в общей папке «Профпробы» (на уровень выше этой папки). На компьютере, который раздаёт пробы, нужен Python 3. Выполни:

```sh
python3 -m http.server 8080
```

Открой в браузере: http://localhost:8080/weblab/

Держи терминал открытым во время работы. Остановка сервера — Ctrl+C. Если команда python3 не найдена или используется Windows, смотри общий README в папке «Профпробы».

## Что делать ученику

1. Меняй подготовленные поля и выполняй задания по порядку.
2. Добавляй содержание и пробуй оформление через CSS.
3. В конце открой готовую страницу в режиме просмотра.

## Как начать заново

Нажми кнопку со стрелкой сброса в верхней части страницы («Начать заново») и подтверди.

Обновление страницы сохраняет прогресс текущей вкладки. Перед следующим учеником используй сброс.

Это готовая сборка сайта. Открывай её через сервер, а не двойным кликом по index.html. Файлы JS, CSS и папки с ресурсами нужны для работы; переименовывать их не надо.
